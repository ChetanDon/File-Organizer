# Problem Statement: Automated File Organizer & System Health Monitor

## Problem Statement
Digital clutter in target directories (like Downloads) reduces productivity and wastes disk space. Manual sorting is time-consuming and inefficient.

## Scope
A Python system utility that automatically categorizes files based on extension types, monitors system disk space, and maintains execution logs.

## Target Users
Students, developers, and office professionals managing heavy file directories.

## High-Level Features
- Extension-based automatic file sorting
- System disk usage monitoring
- Error logging and unit testing suite
