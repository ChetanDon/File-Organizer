# Automated File Organizer & System Health Monitor

## Overview
A lightweight Python automation utility built to sort unstructured directories into neat categorical folders and log storage metrics.

## Features
- **File Sorting:** Auto-categorizes images, documents, archives, and scripts[cite: 2].
- **Health Check:** Real-time disk storage analytics[cite: 2].
- **Logging System:** Records execution status and errors to `organizer.log`[cite: 3].

## Technologies Used
- Python 3.x (Built-in standard libraries: `os`, `shutil`, `logging`, `unittest`)[cite: 3]
